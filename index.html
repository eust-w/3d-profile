01 / EMBODIED

Robots that keep working — safely.

Not a single demo, but the whole harness that lets a coding agent drive fleets of robots: capability calls, physical feedback, task resumption, safety interlocks and long-term memory.

  • OpenGenieMasterEmbodied Execution Protocol over MCP — admission interlocks, versioned memory, a semantic simulator that models seven failure modes and reproduces five experiments.
  • WorldSpecCanonical world semantics, evidence and validation — compiled to multiple simulators.
  • robodataRobot dataset conversion, inspection, quality analysis and episode segmentation.

02 / REAL → SIM

From the real world to a trainable simulator.

As you scroll, the gaussian cloud “cools” into clean geometry — that is the pipeline itself: capture → 3DGS reconstruction → asset export → simulated evaluation.

  1. CaptureiPhone ARKit / LiDAR / RGB-D — real2simcapture
  2. ReconstructImage/RGBD → 3DGS — images23dgs · gsstudio · COLMAP
  3. ExportMJCF / URDF / USD scene packages — Real2Motrix · real2sim-platform
  4. EvaluateBiGym + MuJoCo + OpenPI with 3-camera recording on AMD ROCm — amd-bigym-3dgs-rocm

03 / AI4AI

AI that builds, verifies and evolves AI.

Agents are not just tools being called — they are part of the R&D loop: skills, protocols, memory and evals close the circle. The live diagram on the right is that loop.

  • agentic-embedded-labAgent-native embedded lab: pluggable simulation, evidence-driven validation, controlled evolution.
  • open-robotics-pluginRobotics skills for Claude Code, Codex, Gemini CLI and Cursor — MuJoCo, perception, planning, sim2real.
  • kakashi · codex-dispatch · actor-mapMulti-repo capability fusion, task queues, requirements → assertable role maps.
  • cityagentLoRA training + W8A8 quantization for evidence-backed extraction.
